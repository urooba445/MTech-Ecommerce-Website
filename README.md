# LuxeCart — E-Commerce Website

A responsive frontend-only fashion and lifestyle storefront built for the MTech Solutions Frontend Development Internship, Batch 01 — Task 02.

## Features
- Home page with hero section, categories and featured products
- Shop page with 10 sample products, search, category filter and sorting
- Product detail page with quantity selection
- Cart with add/remove, quantity controls, subtotal and total
- Checkout form with browser validation and simulated order confirmation
- About page and contact form with a frontend success message
- Responsive layout for desktop, tablet and mobile
- Cart saved in browser `localStorage`

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Keep the `css` and `js` folders alongside the HTML files.

## Deployment
Deploy the entire project folder using Vercel or Netlify. No build command is needed for this static HTML/CSS/JavaScript project. The project root is the folder containing `index.html`.

## Important note
This is a student frontend demo. Product information is sample data. The checkout does not process real orders or payments, and the contact form does not send email. Product photos are loaded from Unsplash and require an internet connection.
